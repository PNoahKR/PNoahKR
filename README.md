## 👋 About Me

안녕하세요! **비즈니스의 맥락을 이해하고, 이를 견고한 시스템으로 구현하는 백엔드 개발자 박지우**입니다.

역사문화학을 전공하고 IT 스타트업에서 서비스 영업/관리 업무를 경험하며,  
사용자와 비즈니스가 실제로 마주하는 문제를 가까이에서 바라볼 수 있었습니다.  
이 경험을 바탕으로 단순히 기능을 만드는 것을 넘어,  
**서비스의 목적과 흐름을 이해하고 안정적인 백엔드 구조로 풀어내는 개발자**를 지향하고 있습니다.

현재는 **Java와 Spring Boot를 중심으로 백엔드 개발**을 공부하고 있으며,  
실시간 협업 서비스, 데이터 정합성 검증, 외부 플랫폼 연동, 비동기 처리 등  
여러 프로젝트를 통해 시스템의 안정성과 확장성을 고민하는 경험을 쌓아가고 있습니다.

낯선 도메인도 빠르게 이해하고, 팀원들과 적극적으로 소통하며,  
사용자에게 필요한 가치를 신뢰할 수 있는 서비스로 전달하는 개발자로 성장하고 싶습니다.
